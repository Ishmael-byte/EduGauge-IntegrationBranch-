# EduGauge Integration Branch

EduGauge is a collaborative academic project designed to streamline educational data management and integration.  
This repository represents the integration branch of the project, showcasing both backend and frontend development.

## Live Demo
[View the project on Netlify](https://edugauge.netlify.app/)

---

## Project Overview
EduGauge was built as part of a group initiative to demonstrate full‑stack development skills, teamwork, and modern web practices.  
The system integrates multiple components to provide a seamless educational platform prototype.

---

## Technologies Used
- Backend & APIs: Node.js, Express.js  
- Frontend: React.js  
- Data Format: JSON  
- Testing & API Development: Thunder Client / Postman  
- Version Control: Git & GitHub  

---

## My Contributions
As the Backend Developer, I focused on:
- Designing and implementing RESTful APIs.
- Structuring backend logic for data flow and integration.
- Ensuring JSON data handling across endpoints.
- Testing APIs using Thunder Client to validate functionality.
- Collaborating with frontend developers to connect APIs with React components.

---

## Features
- User‑friendly educational data interface.
- Backend API endpoints for data retrieval and management.
- Integration between frontend and backend for real‑time updates.
- Deployment on Netlify for easy access and demonstration.
